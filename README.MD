# BookNest 

A personalized book recommendation system using hybrid recommendation techniques.

## Project Overview

BookNest is a recommendation system designed to help users discover books based on their preferences and interactions.

The project explores multiple recommendation approaches, including:

- Popularity-based recommendation
- Content-based filtering
- Collaborative filtering
- Hybrid recommendation

## Dataset

The project uses the Goodbooks-10k dataset.

Raw dataset files are not included in this repository.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook
